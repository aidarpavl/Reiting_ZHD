# 🚂 Рейтинг Жас Дарын

Streamlit приложение для расчета и визуализации рейтинга жилищных домов.

## 🎯 Функциональность

- 📊 Загрузка данных из Excel файла
- 📈 Расчет рейтинга с различными методами нормализации
- 📊 Визуализация данных (графики, диаграммы)
- 📥 Экспорт результатов в Excel и CSV
- 🔍 Поиск и фильтрация данных
- 📊 Статистический анализ

## 🚀 Деплой

Приложение развернуто на Streamlit Cloud:
[https://aidarpavl-reiting-zhd-app.streamlit.app](https://aidarpavl-reiting-zhd-app.streamlit.app)

## 🛠️ Локальный запуск

```bash
# Клонирование репозитория
git clone https://github.com/aidarpavl/Reiting_ZHD.git
cd Reiting_ZHD

# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
streamlit run app.py
